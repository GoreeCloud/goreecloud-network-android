# GoreeCloud Network Android Branding

All branding authority belongs to `GoreeCloud/goreecloud-branding-assets`.

This Android client is part of GoreeCloud Network. Approved Network product artwork is stored at `products/network/app-icon.svg`. Client-local launcher, adaptive-icon, notification, and store artwork are synchronized derivatives only. Any Android-specific branding revision must be created and approved in the unified branding repository before synchronization here.

Branding does not establish network authority, runtime acceptance, or release claims.
